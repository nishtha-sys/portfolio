## Running Locally

```bash
git clone https://github.com/nishtha-sys/portfolio
cd portfolio
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

---

## Deployment

Deployed on **Vercel** via GitHub integration. Every push to `main` auto-deploys.
