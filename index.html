  • Clean Flask REST API — single POST endpoint, validated inputs, structured JSON, graceful error handling for timeouts and auth failures; CORS configured for cross-origin deployment
  • React frontend on Vercel + Flask backend on Render — both live, zero credentials in the public repo; used IBM Bob for architecture review, unit tests, and security audit
